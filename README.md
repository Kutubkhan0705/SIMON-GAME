# 🎮 Simon Game

A simple and interactive **Simon Game** built using **HTML, CSS, and JavaScript**.

The game tests your memory and concentration by generating a random sequence of colored buttons. Your task is to remember and repeat the sequence correctly. As you progress, the sequence becomes longer and the level increases.

## 🎯 How to Play

1. Open the game.
2. Press any key to start.
3. Watch the color that flashes.
4. Click the buttons in the same sequence.
5. Each successful round increases the level.
6. Remember the complete sequence as the game progresses.
7. If you click the wrong button, the game is over.
8. Press any key again to restart.

## 🧠 Game Logic

The game maintains two sequences:

* `gameSeq` – stores the sequence generated by the game.
* `userSeq` – stores the sequence entered by the player.

At every level, the game randomly selects a color and adds it to the game sequence. The player's input is then compared with the generated sequence.

If the sequence is correct, the player moves to the next level. If the player selects the wrong color, the game ends and the score is displayed.
